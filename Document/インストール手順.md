# Docker インストール手順（Ubuntu 24.04 LTS） ※2026年2月2日(月)時点

## 1. 事前確認

```bash
現在のOS確認
lsb_release -a

以下のように表示されればOK
Ubuntu 24.04 LTS
```

```bash
古いDockerがあれば削除
sudo apt remove -y docker docker-engine docker.io containerd runc

パッケージ情報を最新化
sudo apt update

Dockerインストールに必要なツールを入れる　※ca-certificates：HTTPS通信を安全にする
sudo apt install -y ca-certificates curl

Docker公式GPGキーを登録　※GPG：公式の配布元であることを保証するPrivacyGuard証明書
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc

読み取り権限付与
sudo chmod a+r /etc/apt/keyrings/docker.asc
```

```bash
Docker公式リポジトリを追加　※aptが「どこからDockerをダウンロードするか」を登録する
sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: noble
Components: stable
Signed-By: /etc/apt/keyrings/docker.asc
EOF

再度updateしてdockerリポジトリの追加を反映
sudo apt update
```

## 2. インストール

```bash
Docker本体をインストール
※以下、インストール内容
docker-ce：Docker本体
docker-ce-cli：dockerコマンド
containerd：コンテナ実行エンジン
compose-plugin：docker compose
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

Dockerが起動しているか確認
sudo systemctl status docker

以下が出ればOK
Active: active (running)
```

```bash
sudoなしでdockerを使えるようにする
sudo usermod -aG docker $USER

権限付与を反映させるため再起動する。
sudo reboot
```

## 3. 動作確認

```bash
動作確認
docker ps
エラーが出なければOK

最終確認（hello-world）
sudo systemctl status docker
以下が出ればOK
Active: active (running)
```
